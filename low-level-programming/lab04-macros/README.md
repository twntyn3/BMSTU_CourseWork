# Лабораторная №4. Макросредства

Макросы для байтовых и словных переменных, блоки повторения, создание массивов и проверка параметров. NASM, 16-битная COM-программа.

Исходник восстановлен из финального листинга чата `lowlevel`; применено указанное там исправление `DEF Z, B, 4` без завершающей запятой.
