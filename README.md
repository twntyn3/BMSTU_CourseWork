# BMSTU Coursework

Лабораторные работы и учебные проекты по направлению «Прикладная математика и информатика», МГТУ им. Н. Э. Баумана, ИУ9.

| Раздел | Что внутри | Языки и технологии |
|---|---|---|
| [C++](cpp) | 9 работ: память, шаблоны, контейнеры, операторы и итераторы | C++20, STL |
| [Java](java) | 13 работ: ООП, обобщения, коллекции, лексический и синтаксический анализ | Java |
| [Компьютерные сети](computer-networks) | HTTP-сервер, загрузка страниц и парсинг HTML-таблиц | Go, net/http, context |

| [Операционные системы](operating-systems) | Лабораторные для ReactOS и NetBSD, исходники и описания среды | C, системное программирование, виртуальные машины |
| [Летняя практика 2026](SummerPrac26) | Материалы практики | См. содержимое раздела |
| [Низкоуровневое программирование](low-level-programming) | Арифметика, макросредства и защищённый режим | x86, NASM, MASM/TASM |
