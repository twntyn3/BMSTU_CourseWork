# BMSTU · Computer Science Coursework

**Матвей Хромов · МГТУ им. Н. Э. Баумана · ИУ9**

01.03.02 «Прикладная математика и информатика»

Учебные программы и практические проекты: от классов и контейнеров на C++ до разбора языков на Java, лабораторных по операционным системам и летней практики.

## Навигация

| Раздел | Что внутри | Языки и технологии |
|---|---|---|
| [C++](cpp) | 7 работ: память, шаблоны, контейнеры, операторы и итераторы | C++20, STL |
| [Java](java) | 5 работ: ООП, обобщения, коллекции, лексический и синтаксический анализ | Java |
| [Компьютерные сети](computer-networks) | HTTP-сервер, загрузка страниц и парсинг HTML-таблиц | Go, net/http, context |
| [Операционные системы](operating-systems) | Лабораторные для ReactOS и NetBSD, исходники и описания среды | C, системное программирование, виртуальные машины |
| [Летняя практика 2026](SummerPrac26) | Материалы практики | См. содержимое раздела |

## С чего начать просмотр

- **[ASCII-последовательность](cpp/lab07-ascii-sequence)** — владение динамической памятью, копирование и присваивание.
- **[Объединяемый словарь](cpp/lab09-merging-map)** — шаблонный контейнер, операторы и вложенные структуры.
- **[Разбор объявлений](java/lab11-declaration-parser)** — отдельные лексер, токены и рекурсивный парсер.
- **[Операционные системы](operating-systems)** — работа с двумя семействами ОС и их окружением.

## Запуск

```bash
git clone https://github.com/twntyn3/BMSTU_CourseWork.git
cd BMSTU_CourseWork/cpp/lab08-stack
c++ -std=c++20 main.cpp -o demo
./demo
```

Лабораторные независимы. Для каждой добавленной программы есть README с командами сборки и запуска. Подробности локальной проверки — в [VALIDATION.md](VALIDATION.md).

## О материалах

Архив пополняется по мере разбора собственных исходников. Это подборка выполненных работ, а не полный учебный план и не перечень всех освоенных дисциплин. Исходные учебные реализации сохранены; ограничения и состояние проверки указаны отдельно. Образы ОС, окружения IDE, секреты и результаты сборки исключены из Git.
