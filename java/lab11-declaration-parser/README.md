# Лексический и синтаксический анализ

Токенизация и рекурсивный разбор объявлений.

Учебная работа на Java. Исходники перенесены из локального проекта `lab11`.

## Сборка и запуск

Из этой папки, с JDK 17 или новее:

```bash
mkdir -p build
javac -encoding UTF-8 -d build src/*.java
java -cp build Main
```

Программа читает объявление из стандартного ввода до EOF. Пример:

```bash
printf 'int*x\n' | java -cp build Main
```
