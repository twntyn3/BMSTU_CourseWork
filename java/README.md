# Java: языки и методы программирования

Отдельные программы по ООП, коллекциям, обобщениям и разбору формального языка.

| Работа | Тема |
|---|---|
| [Абитуриенты](lab03-applicants) | Класс Applicant и сортировка объектов. |
| [Объединение итераторов](lab04-joined-iterable) | Обобщённый Iterable и обход двух последовательностей. |
| [Квадратный многочлен](lab05-quadratic-polynomial) | Stream API, суммы и произведения действительных корней по формулам Виета. |
| [Арифметические прогрессии](lab05-arithmetic-progressions) | Работа с коллекцией прогрессий. |
| [Лексический и синтаксический анализ](lab11-declaration-parser) | Токенизация и рекурсивный разбор объявлений. |

Каждая работа компилируется отдельно: имена классов в разных лабораторных могут повторяться.
