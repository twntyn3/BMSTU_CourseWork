# Квадратный многочлен

Stream API, суммы и произведения действительных корней по формулам Виета.

Учебная работа на Java. Исходники перенесены из локального проекта `lab5var2`.

## Сборка и запуск

Из этой папки, с JDK 17 или новее:

```bash
mkdir -p build
javac -encoding UTF-8 -d build src/*.java
java -cp build Test
```
