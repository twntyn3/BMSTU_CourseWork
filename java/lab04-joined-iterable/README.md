# Объединение итераторов

Обобщённый Iterable и обход двух последовательностей.

Учебная работа на Java. Исходники перенесены из локального проекта `lab431march`.

## Сборка и запуск

Из этой папки, с JDK 17 или новее:

```bash
mkdir -p build
javac -encoding UTF-8 -d build src/*.java
java -cp build Test
```
