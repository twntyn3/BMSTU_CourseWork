# Абитуриенты

Класс Applicant и сортировка объектов.

Учебная работа на Java. Исходники перенесены из локального проекта `lab3`.

## Сборка и запуск

Из этой папки, с JDK 17 или новее:

```bash
mkdir -p build
javac -encoding UTF-8 -d build src/*.java
java -cp build Test
```

Пример входных данных: количество абитуриентов, затем имя и три оценки для каждого.

```text
2
Alice
90 80 70
Bob
100 90 80
```

Ожидаемый порядок вывода: Bob (270), Alice (240).
