# Базы данных

Лабораторные работы по курсу «Базы данных», МГТУ им. Н. Э. Баумана, ИУ9.

Общая предметная область — **система управления киберспортивными турнирами**: организаторы, дисциплины, турниры, команды и результаты участия.

| Работа | Содержание | Отчёт |
|---|---|---|
| [ER-модель](lab01-er-model) | Моделирование системы управления киберспортивными турнирами: сущности, атрибуты, идентификаторы и кардинальности связей. | [PDF](lab01-er-model/report.pdf) |
| [Модель семантических объектов](lab02-semantic-objects) | Объекты предметной области, простые и объектные атрибуты, групповой атрибут участия в турнире и обоснование кардинальностей. | [PDF](lab02-semantic-objects/report.pdf) |
| [Реляционная модель](lab03-relational-model) | Преобразование ER-модели в таблицы, выбор типов данных, первичных, внешних и альтернативных ключей, правила ссылочной целостности. | [PDF](lab03-relational-model/report.pdf) |

## Материалы
