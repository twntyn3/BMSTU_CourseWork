# SMTP и хранение получателей в MySQL

Учебный проект из локальных исходников. Зависимости — `go.mod`.

Пароли и почтовые реквизиты вынесены в переменные окружения `DB_PASSWORD`, `SMTP_PASSWORD`, `SMTP_USER`, `SMTP_FROM`. Пример имён — в `.env.example`; файл не загружается программой автоматически.
