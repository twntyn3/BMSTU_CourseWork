# Компьютерные сети

## [HTTP scraper на Go](http-scraper)

HTTP-сервер с HTML-интерфейсом, клиентом для загрузки страниц и разбором таблиц. Демонстрирует обработчики запросов, тайм-ауты, отмену операций через context, логирование и корректное завершение сервера.

Учебный проект перенесён из локальных исходников. Команды запуска и ограничения приведены в README проекта.
