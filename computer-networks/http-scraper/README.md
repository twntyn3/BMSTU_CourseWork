# HTTP scraper · Go

Учебное веб-приложение: загружает HTML-страницу с таблицей курсов криптовалют, извлекает строки и показывает их в браузере.

## Что реализовано

- HTTP-сервер на `net/http` и отдельные обработчики.
- HTTP-клиент с тайм-аутами и ограничением размера ответа.
- Разбор HTML через `golang.org/x/net/html`.
- Шаблон страницы на `html/template`.
- Логирование запросов и завершение по SIGINT/SIGTERM.

## Структура

```text
main.go          обработчики, сервер, graceful shutdown
internal/fetch/  загрузка страниц
internal/parse/  разбор HTML и таблиц
internal/tpl/    HTML-шаблон
```

## Локальный запуск

Требуется Go 1.22 или новее. Из этой папки:

```bash
go mod download
go run .
```

Открыть `http://localhost:8080`. Для остановки — Ctrl+C.

| Путь | Назначение |
|---|---|
| `/` | Таблица с источника `https://myfin.by/crypto-rates` |
| `/healthz` | Проверка доступности сервера: `ok` |
| `/inspect` | Заголовки таблиц и первые строки для диагностики |

Параметр `src` позволяет выбрать источник HTML; `debug=1` у `/` показывает начало ответа источника.

## Ограничения

Это локальная учебная демонстрация. Сервер слушает `:8080`; режим произвольного `src` не предназначен для публичного развёртывания без ограничения исходящих адресов. Извлечение курсов зависит от внешней HTML-разметки, поэтому пустая таблица требует проверки источника. Вызов `/healthz` не проверяет загрузку внешних страниц.

Исходники сохранены без изменения логики. Подробности проверки — в [VALIDATION.md](../../VALIDATION.md).
