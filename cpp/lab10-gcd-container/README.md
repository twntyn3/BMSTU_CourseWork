# Контейнер НОД

Пользовательский итератор по соседним парам целых чисел.

Учебная работа по C++. Исходники перенесены из локального проекта `lab10var2`.

## Сборка и запуск

Из этой папки, с Clang или GCC и поддержкой C++20:

```bash
c++ -std=c++20 GCDContainer.cpp main.cpp -o demo
./demo
```

`main.cpp` содержит демонстрационный сценарий. Успешный запуск демонстрации не заменяет проверку всех граничных случаев.
