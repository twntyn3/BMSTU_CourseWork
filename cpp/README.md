# C++: языки и методы программирования

Классы, управление памятью, шаблоны, контейнеры, перегрузка операторов и итераторы.

| Работа | Тема |
|---|---|
| [ASCII-последовательность](lab07-ascii-sequence) | Динамическая память, копирование, присваивание и проверка палиндрома. |
| [Шаблонный стек](lab08-stack) | Шаблоны классов, ограничение вместимости и операции LIFO. |
| [Двусвязный список](lab08-linked-list) | Узлы, вставка, поиск, удаление и специализация для int. |
| [Объединяемый словарь](lab09-merging-map) | Перегрузка операторов и объединение значений по общим ключам. |
| [Линейные неравенства](lab09-linear-inequalities) | Шаблоны, арифметические операции и проверка выполнения неравенства. |
| [Контейнер треугольников](lab10-triangle-container) | Пользовательский итератор по тройкам отрезков и изменение периметра. |
| [Контейнер НОД](lab10-gcd-container) | Пользовательский итератор по соседним парам целых чисел. |

Каждая работа собирается отдельно. Инструкции находятся в её README.

- [Удаление комментариев](lab12-strip-comments) — Обработка C-файлов и конечный автомат удаления комментариев.

- [Обработка текстовых файлов](lab12-text-files) — Перемешивание внутренних букв слов и обход каталога.
