# ASCII-последовательность

Динамическая память, копирование, присваивание и проверка палиндрома.

Учебная работа по C++. Исходники перенесены из локального проекта `lab7`.

## Сборка и запуск

Из этой папки, с Clang или GCC и поддержкой C++20:

```bash
c++ -std=c++20 implementation.cpp main.cpp -o demo
./demo
```

`main.cpp` содержит демонстрационный сценарий. Успешный запуск демонстрации не заменяет проверку всех граничных случаев.
