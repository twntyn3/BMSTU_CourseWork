# Шаблонный стек

Шаблоны классов, ограничение вместимости и операции LIFO.

Учебная работа по C++. Исходники перенесены из локального проекта `lab8`.

## Сборка и запуск

Из этой папки, с Clang или GCC и поддержкой C++20:

```bash
c++ -std=c++20 main.cpp -o demo
./demo
```

`main.cpp` содержит демонстрационный сценарий. Успешный запуск демонстрации не заменяет проверку всех граничных случаев.
