# Контейнер треугольников

Пользовательский итератор по тройкам отрезков и изменение периметра.

Учебная работа по C++. Исходники перенесены из локального проекта `lab10cpp`.

## Сборка и запуск

Из этой папки, с Clang или GCC и поддержкой C++20:

```bash
c++ -std=c++20 TriangleContainer.cpp main.cpp -o demo
./demo
```

`main.cpp` содержит демонстрационный сценарий. Успешный запуск демонстрации не заменяет проверку всех граничных случаев.
